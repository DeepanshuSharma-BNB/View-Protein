Meta Ray-Ban Display web app

View Protein

Use this page to add or re-add View Protein to your glasses. No phone-to-glasses pairing code is needed.

Add to Meta AI ↗ Open the web app in a browser

If the button does not work: In the Meta AI phone app, go to App connections → Web apps → Add a web app. Enter the name View Protein and this URL:

https://deepanshusharma-bnb.github.io/View-Protein/

Developer Mode must be enabled. This link makes reinstallation easier; a web app cannot prevent the Meta AI app from removing a registered entry. Keep this page bookmarked so it is easy to re-add if that happens.
